# Descripción del Proyecto
## CloudString es una organización orientada al desarrollo de software y distribución de infraestructura tecnológica. El presente módulo automatiza el proceso de *Integración y Despliegue Continuo (CI/CD)* para garantizar la calidad del código, reducir los tiempos de entrega y minimizar errores humanos en la publicación de versiones.

# Declaracion de Uso de Inteligencia Artificial #

Con el motivo de ofrecer una transparencia academica para el Trabajo Practico Integrador, se puntializa el uso supervisado de herramientas de Inteligencia Artificial durante el desarrollo del proyecto:

## 1. Herramientas Utilizadas: 
Se utilizo el asistente virtual "Gemini" para la organizacion y explicacion de varios conceptos del presente trabajo practico, como así tambien puntualizarlos para la formulacion del mismo. Asimismo, se utilizo "Gemini Notebook" con el objetivo de estructurar y cumplir con la totalidad de los enunciados de una manera satisfactoria. 

## 2. Justificación Crítica de Prompts Utilizados:
Los prompts diseñados para interactuar con las herramientas se enfocaron en tres ejes principales: 

### A) Estructuración y Modelado: Prompts orientados a estructurar, traducir y vertir las especificaciones teóricas de la materia al caso de estudio
### B) Estandarización de Formatos: aplicados a la conversión de requerimientos en "Historias de Usuario (HU)" bajo la fórmula formal de "¿Como?" [rol] + "Quiero" [acción] + "Para" [beneficio]
### C) Verificación de Coherencia: dirigidos al control, para garantizar una correcta alineación entre el organigrama de CloudString, las tablas del Diccionario de Datos y el flujo de procesos. 

## 3. Correcciones y Auditoría Humana:
Cada resultado propuesto por la IA fue sometido a una revisión crítica y edición manual por parte del estudiante, efectuando las siguientes correcciones clave: 

### A) Se corrigió la sintaxis de las actividades para garantizar el uso estricto de "verbos en infinitivo" y se ajustó la naturaleza de las conexiones. 
### B) Se revisaron y corregieron inconsistencias ortográficas y tipográficas en los nombres de los campos técnicos del Diccionario de Datos
### C) Se ajustaron los umbrales y metas de los "KPIs" para garantizar su viabilidad técnica en un entorno real de integración continua. 

## 4. Soberanía y Contenido Final:
La toma de decisiones, diagramacion grafica de herramientas visuales, el versionado en Git/GitHub y la integración del documento final en PDF fueron ejecutados íntegramente por quien suscribe.
